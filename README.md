# Sukiyaki Instruments

A shape-driven composition instrument for the browser.
Place primitive shapes in a ring, move, turn and flip them over time; the score on the left records every move.

- **Open:** https://takaakikotera.github.io/sukiyaki-instruments/
- On a tablet, open it in Safari and use *Share → Add to Home Screen* to run it full screen.
- Pieces are saved only in your own browser (localStorage). Nothing is sent anywhere.

Built with [Tone.js](https://tonejs.github.io/).
